    Introduction

    About polars-pairing

    polars-pairing is a plugin that provides pairing functions to Polars. These functions encode a pair of natural numbers into a single natural number.

    This plugin implements six pairing functions (Hagen1, Szudzik2, Cantor3, Peter4, Rosenberg-Strong5, and Thotakura6), along with their corresponding unpairing functions, as Polars expressions. The pairing functions take two nonnegative integer columns as input and produce a single column containing the encoded pair. Conversely, the unpairing functions accept a single column as input and generate a struct column containing the values of the original pair.

    Installation

    polars-pairing can be installed via Python's pip:

    pip install polars-pairing

    Example

    >>> import polars as pl
>>> import polars_pairing as plp

>>> df = pl.DataFrame({
...     "a": [1, 2, 38, 4],
...     "b": [5, 6, 77, 80]
... })
>>> df.select(plp.col("a").pairing.pair(plp.col("b")).alias("pair"))
shape: (4, 1)

│ pair │
│ ---  │
│ u64  │
╞══════╡
│ 28   │
│ 40   │
│ 6006 │
│ 6408 │
└──────┘

>>> df.select(
...     plp.col("a")
...     .pairing.pair(plp.col("b"), method="hagen") # (1)!

...     plp.col("a")
...     .pairing.pair(plp.col("b"), method="szudzik")
...     .alias("szudzik_pair"),
...     plp.col("a")
...     .pairing.pair(plp.col("b"), method="cantor")
...     .alias("cantor_pair"),
...     plp.col("a")

...     plp.col("a")

...     .alias("rosenberg_strong_pair"),
...     plp.col("a")
...     .pairing.pair(plp.col("b"), method="thotakura")

    1. By default, the Hagen pairing function is used, but you can specify alternative functions. The available methods are: hagen, szudzik, cantor, peter, rosenberg_strong, and thotakura.
    2. The unpairing functions return a struct column containing the values of the original pair.
